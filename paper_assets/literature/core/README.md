# 核心引用文献

这个目录只放当前论文初稿参考文献中已经实际引用的 25 篇核心论文资料，并按中文、英文分开保存。

## 目录说明

| 路径 | 作用 |
|---|---|
| `chinese/pdfs/` | 当前论文已引用中文文献 PDF |
| `chinese/references.bib` | 当前论文已引用中文文献 BibTeX |
| `english/pdfs/` | 当前论文已引用英文文献 PDF |
| `english/references.bib` | 当前论文已引用英文文献 BibTeX |
| `references.bib` | 中文和英文核心 BibTeX 的总表 |
| `missing-core-references.md` | 原缺失核心文献的补齐状态 |

## 使用建议

写“相关工作”中文研究部分时，优先查看 `chinese/`。

写“算法基础、数据集来源、基础模型和损失函数”部分时，优先查看 `english/`。

`paper_assets/literature/chinese_multisite/` 中保留了原来的三份文献检索结果，作为完整归档和备用资料。这里的 `core/` 只用于写论文时快速查找已经引用的核心资料。
